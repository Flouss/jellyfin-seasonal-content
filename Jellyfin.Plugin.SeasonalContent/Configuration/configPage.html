Connection

The scheme://host:port that both this server's own transcoder and every client device on your LAN can reach. Prefer a LAN IP over 127.0.0.1 or a reverse-proxied hostname. Left empty, stub playback is disabled.
Stub base URL is empty. Titles the server doesn't own will not be playable until this is set.
Leave blank to keep the currently saved key.

Stub library

Add this exact path once, on this server, as a Movies-type library (Dashboard → Libraries → Add Media Library), with the TMDb metadata fetcher enabled. Every restricted user also needs explicit access granted to it, or their collections will silently show missing stubs.
