Connection

The scheme://host:port that both this server's own transcoder and every client device on your LAN can reach. Prefer a LAN IP over 127.0.0.1 or a reverse-proxied hostname. Left empty, stub playback is disabled.

Stub libraries

This plugin needs a Movies-type library at the movie path below, a Shows-type library at the TV path below (both with the TMDb metadata fetcher enabled), and a Collections library so the collections it creates are browsable. Click "Set up libraries" to create whichever of the three don't already exist - safe to click again later, it skips anything already set up. Every restricted user still needs explicit access granted to both stub libraries by hand, or their collections will silently show missing stubs.

Lists

Each list is fetched from MDBList and can contain both movies and TV shows - both are added to the same collection.

Requests

Extra movie quality profiles (optional)

Add one or more extra Radarr server/profile pairs to offer a quality version picker on movie playback (the picker also needs the Radarr server and profile above set, as the default version). Leave empty to keep one plain stub per movie with no picker.

Extra TV quality profiles (optional)

Same as above, for TV shows (Sonarr).
